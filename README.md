# Habit Tracker

Android app (Kotlin) for tracking habits, including time-based ones via a timer.
Also a learning project: practicing a structured AI-assisted workflow with Claude Code (skills, subagents).
Workflow: requirements -> design -> plan -> implementation, with a human approval between phases.
Docs live in `docs/`, workflow tooling in `.claude/`, the app in `android/` (not created yet).
Status: requirements phase.
